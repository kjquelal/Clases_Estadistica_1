Error estándar

Ejercicio 1 Básico

Una población tiene desviación estándar $\sigma = 20$. Se toman muestras aleatorias de tamaño $n = 25$. Calcula el error estándar de la media muestral.

Ver solución
$$\sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}} = \frac{20}{\sqrt{25}} = \frac{20}{5} = 4$$
Ejercicio 2 Intermedio

Una población tiene $\sigma = 18$. Calcula el error estándar de la media muestral para una muestra de tamaño $n = 9$ y para una de tamaño $n = 36$. ¿Qué relación observas entre los dos tamaños de muestra y los dos errores estándar obtenidos?

Ver solución
$$\sigma_{\bar{X}}\big|_{n=9} = \frac{18}{\sqrt{9}} = \frac{18}{3} = 6$$
$$\sigma_{\bar{X}}\big|_{n=36} = \frac{18}{\sqrt{36}} = \frac{18}{6} = 3$$

El tamaño de muestra se multiplicó por 4 (de 9 a 36) y el error estándar se redujo exactamente a la mitad (de 6 a 3). Esto confirma la relación $\sigma_{\bar{X}} = \sigma/\sqrt{n}$: para reducir el error estándar a la mitad hace falta cuadruplicar el tamaño de la muestra, no solo duplicarlo.

Distribución muestral de la media

Ejercicio 3 Básico

Una población tiene $\mu = 100$ y $\sigma = 15$. Se toma una muestra aleatoria de $n = 36$. Calcula la probabilidad de que la media muestral sea mayor a 102.5.

Ver solución
$$\sigma_{\bar{X}} = \frac{15}{\sqrt{36}} = \frac{15}{6} = 2.5$$
$$Z = \frac{102.5 - 100}{2.5} = 1.0$$
$$P(\bar{X} > 102.5) = 1 - \Phi(1.0) = 1 - 0.8413 = 0.1587$$
Ejercicio 4 Básico

La vida útil de cierto componente electrónico tiene media $\mu = 200$ horas y desviación estándar $\sigma = 28$ horas. Se toma una muestra aleatoria de $n = 49$ componentes. Calcula la probabilidad de que la vida útil promedio de la muestra sea menor a 196 horas.

Ver solución

Como $n = 49 \ge 30$, aplica el Teorema del Límite Central.

$$\sigma_{\bar{X}} = \frac{28}{\sqrt{49}} = \frac{28}{7} = 4$$
$$Z = \frac{196 - 200}{4} = -1.0$$

Como nos preguntan por la probabilidad de que $\bar{X}$ sea menor que 196, usamos simetría: $P(Z \le -1.0) = 1 - \Phi(1.0)$.

$$P(\bar{X} < 196) = 1 - \Phi(1.0) = 1 - 0.8413 = 0.1587$$
Ejercicio 5 Intermedio

Una fábrica produce tornillos con longitud media $\mu = 5$ cm y $\sigma = 0.4$ cm. Se toma una muestra aleatoria de $n = 64$ tornillos. Calcula la probabilidad de que la media muestral esté entre 4.9 y 5.1 cm.

Ver solución
$$\sigma_{\bar{X}} = \frac{0.4}{\sqrt{64}} = \frac{0.4}{8} = 0.05$$
$$Z_1 = \frac{4.9-5}{0.05} = -2.0 \qquad Z_2 = \frac{5.1-5}{0.05} = 2.0$$

Usamos simetría: $P(Z \le -2.0) = 1 - \Phi(2.0) = 1 - 0.9772 = 0.0228$.

$$P(4.9 < \bar{X} < 5.1) = \Phi(2.0) - [1-\Phi(2.0)] = 0.9772 - 0.0228 = 0.9544$$

Distribución muestral de la proporción

Ejercicio 6 Avanzado

Se sabe que el 50% de una población apoya una propuesta ($p = 0.5$). Se encuesta a una muestra aleatoria de $n = 100$ personas. Calcula la probabilidad de que la proporción muestral $\hat{p}$ sea mayor al 57.5%.

Ver solución

Verificamos las condiciones: $np = 50 \ge 5$ y $n(1-p) = 50 \ge 5$. ✓

$$\sigma_{\hat{p}} = \sqrt{\frac{p(1-p)}{n}} = \sqrt{\frac{0.5(0.5)}{100}} = \sqrt{0.0025} = 0.05$$
$$Z = \frac{0.575 - 0.5}{0.05} = 1.5$$
$$P(\hat{p} > 0.575) = 1 - \Phi(1.5) = 1 - 0.9332 = 0.0668$$
Ejercicio 7 Intermedio

Se sabe que el 20% de los clientes de una tienda paga con tarjeta de crédito ($p = 0.2$). Se toma una muestra aleatoria de $n = 100$ clientes. Calcula la probabilidad de que la proporción muestral $\hat{p}$ sea menor al 16%.

Ver solución

Verificamos las condiciones: $np = 20 \ge 5$ y $n(1-p) = 80 \ge 5$. ✓

$$\sigma_{\hat{p}} = \sqrt{\frac{p(1-p)}{n}} = \sqrt{\frac{0.2(0.8)}{100}} = \sqrt{0.0016} = 0.04$$
$$Z = \frac{0.16 - 0.2}{0.04} = -1.0$$

Usamos simetría: $P(Z \le -1.0) = 1 - \Phi(1.0)$.

$$P(\hat{p} < 0.16) = 1 - \Phi(1.0) = 1 - 0.8413 = 0.1587$$

Distribución de probabilidad, valor esperado y varianza

Ejercicio 1 Básico

Una variable aleatoria $X$ tiene la siguiente distribución de probabilidad, donde falta un valor:

$x$1234
$p(x)$0.10.30.4?

Encuentra el valor faltante y calcula $E(X)$.

Ver solución

Como las probabilidades deben sumar 1:

$$p(4) = 1 - (0.1+0.3+0.4) = 1 - 0.8 = 0.2$$
$$E(X) = 1(0.1) + 2(0.3) + 3(0.4) + 4(0.2) = 0.1+0.6+1.2+0.8 = 2.7$$
Ejercicio 2 Básico

Una variable aleatoria $X$ tiene la distribución:

$x$012
$p(x)$0.50.30.2

Calcula $E(X)$, $\text{Var}(X)$ y la desviación estándar de $X$.

Ver solución
$$E(X) = 0(0.5) + 1(0.3) + 2(0.2) = 0.7$$
$$E(X^2) = 0^2(0.5) + 1^2(0.3) + 2^2(0.2) = 0.3 + 0.8 = 1.1$$
$$\text{Var}(X) = 1.1 - 0.7^2 = 1.1 - 0.49 = 0.61 \qquad \sigma = \sqrt{0.61} \approx 0.781$$
Ejercicio 3 Intermedio

Un juego de la feria de bienestar universitario consiste en pagar por un boleto y girar una ruleta que entrega los siguientes premios (en miles de pesos), con las probabilidades indicadas:

$x$ (miles $)051020
$p(x)$0.40.30.20.1

Calcula el premio esperado $E(X)$ y la varianza $\text{Var}(X)$. Según tu resultado, ¿cuánto debería cobrar la feria por el boleto para no perder dinero en promedio?

Ver solución
$$E(X) = 0(0.4) + 5(0.3) + 10(0.2) + 20(0.1) = 0 + 1.5 + 2 + 2 = 5.5$$
$$E(X^2) = 0^2(0.4) + 5^2(0.3) + 10^2(0.2) + 20^2(0.1) = 7.5 + 20 + 40 = 67.5$$
$$\text{Var}(X) = 67.5 - 5.5^2 = 67.5 - 30.25 = 37.25 \qquad \sigma = \sqrt{37.25} \approx 6.10$$

El premio esperado es $5.5$ (miles de pesos), es decir, $\$5{,}500$. Para no perder dinero en promedio, la feria debería cobrar al menos $\$5{,}500$ por boleto.

Distribución binomial

Ejercicio 4 Intermedio

Un examen tiene 5 preguntas de verdadero/falso. Un estudiante responde al azar, así que cada pregunta tiene probabilidad $p = 0.5$ de acertar, de forma independiente. Sea $X$ el número de respuestas correctas. Calcula $P(X = 3)$, $E(X)$ y $\text{Var}(X)$.

Ver solución

$X$ sigue una distribución binomial con $n = 5$, $p = 0.5$.

$$P(X=3) = \binom{5}{3}(0.5)^3(0.5)^2 = 10 \cdot (0.5)^5 = \frac{10}{32} = 0.3125$$
$$E(X) = np = 5(0.5) = 2.5 \qquad \text{Var}(X) = np(1-p) = 5(0.5)(0.5) = 1.25$$
Ejercicio 5 Intermedio

En una línea de producción, la probabilidad de que un artículo salga defectuoso es $p = 0.05$, de forma independiente entre artículos. Se toma una muestra de $n = 10$ artículos. Sea $X$ el número de artículos defectuosos en la muestra. Calcula $P(X = 2)$, $E(X)$ y $\text{Var}(X)$.

Ver solución

$X$ es binomial con $n = 10$, $p = 0.05$.

$$P(X=2) = \binom{10}{2}(0.05)^2(0.95)^8 = 45(0.0025)(0.66342) \approx 0.0746$$
$$E(X) = np = 10(0.05) = 0.5 \qquad \text{Var}(X) = np(1-p) = 10(0.05)(0.95) = 0.475$$

Es decir, en promedio se espera medio artículo defectuoso por cada muestra de 10, y hay aproximadamente un 7.46% de probabilidad de encontrar exactamente 2 defectuosos.

Ejercicio 6 Avanzado

Una encuesta reciente indica que el 70% de los estudiantes universitarios ha usado alguna aplicación de estudio (flashcards, resúmenes, etc.) en el último mes. Se seleccionan al azar 6 estudiantes de forma independiente. Sea $X$ el número de ellos que ha usado una aplicación de estudio. Calcula: (a) $P(X = 4)$, (b) $P(X \ge 5)$, y (c) $E(X)$ y $\text{Var}(X)$.

Ver solución

$X$ es binomial con $n = 6$, $p = 0.7$.

(a)

$$P(X=4) = \binom{6}{4}(0.7)^4(0.3)^2 = 15(0.2401)(0.09) = 0.324135$$

(b) $P(X \ge 5) = P(X=5) + P(X=6)$, ya que son los únicos valores que faltan para llegar a $n = 6$.

$$P(X=5) = \binom{6}{5}(0.7)^5(0.3)^1 = 6(0.16807)(0.3) = 0.302526$$
$$P(X=6) = \binom{6}{6}(0.7)^6(0.3)^0 = 1(0.117649)(1) = 0.117649$$
$$P(X \ge 5) = 0.302526 + 0.117649 = 0.420175$$

(c)

$$E(X) = np = 6(0.7) = 4.2 \qquad \text{Var}(X) = np(1-p) = 6(0.7)(0.3) = 1.26$$

Ejercicio 7 Avanzado

Un vendedor cierra una venta en cada visita que hace con probabilidad $p = 0.3$, de forma independiente. Hace 4 visitas en un día. Sea $X$ el número de ventas cerradas. Calcula: (a) $P(X = 2)$, (b) $P(X \ge 1)$ usando la regla del complemento, y (c) $E(X)$ y $\text{Var}(X)$.

Ver solución

$X$ es binomial con $n = 4$, $p = 0.3$.

(a)

$$P(X=2) = \binom{4}{2}(0.3)^2(0.7)^2 = 6(0.09)(0.49) = 0.2646$$

(b) Es más fácil calcular primero $P(X = 0)$ y usar el complemento.

$$P(X=0) = (0.7)^4 = 0.2401$$
$$P(X \ge 1) = 1 - P(X=0) = 1 - 0.2401 = 0.7599$$

(c)

$$E(X) = np = 4(0.3) = 1.2 \qquad \text{Var}(X) = np(1-p) = 4(0.3)(0.7) = 0.84$$

Ejercicio 1 Básico

Una variable aleatoria $X$ tiene la siguiente distribución de probabilidad, donde falta un valor:

$x$1234
$p(x)$0.10.30.4?

Encuentra el valor faltante y calcula $E(X)$.

Ver solución

Como las probabilidades deben sumar 1:

$$p(4) = 1 - (0.1+0.3+0.4) = 1 - 0.8 = 0.2$$
$$E(X) = 1(0.1) + 2(0.3) + 3(0.4) + 4(0.2) = 0.1+0.6+1.2+0.8 = 2.7$$
Ejercicio 2 Básico

Una variable aleatoria $X$ tiene la distribución:

$x$012
$p(x)$0.50.30.2

Calcula $E(X)$, $\text{Var}(X)$ y la desviación estándar de $X$.

Ver solución
$$E(X) = 0(0.5) + 1(0.3) + 2(0.2) = 0.7$$
$$E(X^2) = 0^2(0.5) + 1^2(0.3) + 2^2(0.2) = 0.3 + 0.8 = 1.1$$
$$\text{Var}(X) = 1.1 - 0.7^2 = 1.1 - 0.49 = 0.61 \qquad \sigma = \sqrt{0.61} \approx 0.781$$
Ejercicio 3 Intermedio

Un examen tiene 5 preguntas de verdadero/falso. Un estudiante responde al azar, así que cada pregunta tiene probabilidad $p = 0.5$ de acertar, de forma independiente. Sea $X$ el número de respuestas correctas. Calcula $P(X = 3)$, $E(X)$ y $\text{Var}(X)$.

Ver solución

$X$ sigue una distribución binomial con $n = 5$, $p = 0.5$.

$$P(X=3) = \binom{5}{3}(0.5)^3(0.5)^2 = 10 \cdot (0.5)^5 = \frac{10}{32} = 0.3125$$
$$E(X) = np = 5(0.5) = 2.5 \qquad \text{Var}(X) = np(1-p) = 5(0.5)(0.5) = 1.25$$
Ejercicio 4 Avanzado

Un vendedor cierra una venta en cada visita que hace con probabilidad $p = 0.3$, de forma independiente. Hace 4 visitas en un día. Sea $X$ el número de ventas cerradas. Calcula: (a) $P(X = 2)$, (b) $P(X \ge 1)$ usando la regla del complemento, y (c) $E(X)$ y $\text{Var}(X)$.

Ver solución

$X$ es binomial con $n = 4$, $p = 0.3$.

(a)

$$P(X=2) = \binom{4}{2}(0.3)^2(0.7)^2 = 6(0.09)(0.49) = 0.2646$$

(b) Es más fácil calcular primero $P(X = 0)$ y usar el complemento.

$$P(X=0) = (0.7)^4 = 0.2401$$
$$P(X \ge 1) = 1 - P(X=0) = 1 - 0.2401 = 0.7599$$

(c)

$$E(X) = np = 4(0.3) = 1.2 \qquad \text{Var}(X) = np(1-p) = 4(0.3)(0.7) = 0.84$$

Variables aleatorias y distribuciones

Valor esperado, varianza y la distribución binomial.

Teoría y tutorial Ejercicios

Introducción

Una variable aleatoria ($X$) asigna un número a cada resultado de un experimento aleatorio. Puede ser discreta, si toma un conjunto contable de valores (por ejemplo, el número de caras al lanzar 3 monedas), o continua, si puede tomar cualquier valor dentro de un intervalo (por ejemplo, el tiempo que tarda un estudiante en resolver un examen). En este curso trabajamos principalmente con variables discretas.

La distribución de probabilidad de una variable discreta es una tabla o función $p(x) = P(X = x)$ que asigna una probabilidad a cada valor posible. Para que sea válida, todas las probabilidades deben ser mayores o iguales a 0 y deben sumar exactamente 1.

Igual que con un conjunto de datos, una variable aleatoria tiene un valor esperado $E(X)$ (su promedio a largo plazo) y una varianza $\text{Var}(X)$ (qué tan dispersos están sus valores alrededor de $E(X)$).

$$E(X) = \sum_i x_i \, p(x_i) \qquad \text{Var}(X) = \sum_i x_i^2 \, p(x_i) - \big[E(X)\big]^2$$

La distribución binomial

Muchos experimentos consisten en repetir $n$ veces un mismo ensayo con solo dos resultados posibles (éxito o fracaso), con probabilidad de éxito $p$ constante e independiente en cada repetición: por ejemplo, lanzar una moneda varias veces o preguntar a varias personas si aprueban una medida. Si $X$ cuenta el número de éxitos en esas $n$ repeticiones, decimos que $X$ sigue una distribución binomial.

$$P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}, \qquad k = 0, 1, \dots, n$$

Para una variable binomial, el valor esperado y la varianza tienen fórmulas directas, sin necesidad de construir toda la tabla de probabilidades:

$$E(X) = np \qquad \text{Var}(X) = np(1-p)$$

Tutorial resuelto: número de caras al lanzar 3 monedas

Se lanza una moneda equilibrada 3 veces. Sea $X$ = "número de caras obtenidas".

Paso 1 — Espacio muestral

Hay $2^3 = 8$ resultados posibles, todos igualmente probables.

$$\{HHH, HHT, HTH, THH, HTT, THT, TTH, TTT\}$$

Paso 2 — Construir la distribución de probabilidad

Contamos cuántos resultados corresponden a cada valor de $X$.

$x$Resultados$p(x)$
0TTT1/8
1HTT, THT, TTH3/8
2HHT, HTH, THH3/8
3HHH1/8

Paso 3 — Verificar que es una distribución válida

$$\frac{1}{8} + \frac{3}{8} + \frac{3}{8} + \frac{1}{8} = \frac{8}{8} = 1 \ \checkmark$$

Paso 4 — Valor esperado $E(X)$

$$E(X) = 0\cdot\tfrac{1}{8} + 1\cdot\tfrac{3}{8} + 2\cdot\tfrac{3}{8} + 3\cdot\tfrac{1}{8} = \frac{12}{8} = 1.5$$

En promedio, esperamos 1.5 caras cada vez que lanzamos la moneda 3 veces.

Paso 5 — Varianza y desviación estándar

$$E(X^2) = 0^2\cdot\tfrac{1}{8} + 1^2\cdot\tfrac{3}{8} + 2^2\cdot\tfrac{3}{8} + 3^2\cdot\tfrac{1}{8} = \frac{24}{8} = 3$$
$$\text{Var}(X) = E(X^2) - [E(X)]^2 = 3 - 1.5^2 = 3 - 2.25 = 0.75 \qquad \sigma = \sqrt{0.75} \approx 0.866$$

Paso 6 — Reconocer el patrón binomial

Lanzar una moneda 3 veces y contar caras es justamente un experimento binomial con $n = 3$ y $p = 0.5$. Verificamos con las fórmulas directas:

$$E(X) = np = 3(0.5) = 1.5 \ \checkmark \qquad \text{Var}(X) = np(1-p) = 3(0.5)(0.5) = 0.75 \ \checkmark$$

Ambas fórmulas coinciden con lo calculado paso a paso: cuando el experimento cumple las condiciones de una binomial, no hace falta construir toda la tabla.

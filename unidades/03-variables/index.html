Unidad 3

Variables aleatorias y distribuciones

Valor esperado, varianza y la distribución binomial.

Teoría y tutorial Ejercicios

Introducción

En esta unidad estudiamos las variables aleatorias: cómo se distribuye su probabilidad, cómo resumir su comportamiento con el valor esperado y la varianza, y un primer modelo concreto para contar éxitos, la distribución binomial. Cada concepto se presenta por separado, con su definición, su fórmula y un ejemplo breve.

Variable aleatoria discreta y continua

Una variable aleatoria $X$ asigna un número a cada resultado de un experimento aleatorio.

Ejemplo: se lanza una moneda equilibrada 2 veces y $X$ = "número de caras". Los valores posibles son $X \in \{0, 1, 2\}$. Es discreta (valores contables); si en cambio $X$ fuera un tiempo o una estatura, sería continua (cualquier valor en un intervalo). En este curso trabajamos principalmente con variables discretas.

Distribución de probabilidad

La distribución de probabilidad de $X$ es una tabla o función $p(x) = P(X = x)$ que asigna una probabilidad a cada valor posible. (Walpole et al., 2012, cap. 3)

$x$012
$p(x)$0.250.50.25

Para ser válida, las probabilidades deben ser $\ge 0$ y sumar 1: $0.25 + 0.5 + 0.25 = 1$ ✓

Valor esperado E(X)

El valor esperado $E(X)$ es el promedio de $X$ a largo plazo, si el experimento se repitiera muchísimas veces. (Walpole et al., 2012, cap. 4)

$$E(X) = \sum_i x_i \, p(x_i)$$

Con la tabla de arriba: $E(X) = 0(0.25) + 1(0.5) + 2(0.25) = 1$.

No es "el valor más probable en un solo ensayo", sino el promedio que se observaría repitiendo el experimento indefinidamente; también se le llama la media poblacional $\mu$.

Varianza Var(X)

La varianza $\text{Var}(X)$ mide qué tan dispersos están los valores de $X$ alrededor de $E(X)$.

$$\text{Var}(X) = \sum_i x_i^2 \, p(x_i) - \big[E(X)\big]^2$$

Con el mismo ejemplo: $E(X^2) = 0(0.25) + 1(0.5) + 4(0.25) = 1.5$, así que $\text{Var}(X) = 1.5 - 1^2 = 0.5$.

Esta fórmula corta se obtiene expandiendo $E[(X-\mu)^2]$; en la práctica se usa directamente. (Walpole et al., 2012, cap. 4)

La distribución binomial

La distribución binomial modela el número de éxitos $X$ al repetir $n$ veces un ensayo de dos resultados posibles (éxito/fracaso) con probabilidad de éxito $p$ constante. (Walpole et al., 2012, cap. 5; Triola, 2018, cap. 5)

Deben cumplirse cuatro condiciones a la vez:

  1. $n$ repeticiones idénticas (los "ensayos").
  2. Cada ensayo tiene solo dos resultados: éxito o fracaso.
  3. La probabilidad de éxito $p$ es la misma en cada ensayo.
  4. Los ensayos son independientes entre sí.
$$P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}, \qquad k = 0, 1, \dots, n$$

$\binom{n}{k}$ cuenta de cuántas formas se pueden elegir los $k$ ensayos exitosos entre los $n$ totales.

$$E(X) = np \qquad \text{Var}(X) = np(1-p)$$

Nuestro ejemplo (2 lanzamientos, $p=0.5$) es justamente una binomial con $n=2$: $E(X) = np = 2(0.5) = 1$ ✓ y $\text{Var}(X) = np(1-p) = 2(0.5)(0.5) = 0.5$ ✓ — coinciden con lo calculado arriba.

Resumen — para recordar

  • Variable aleatoria $X$ — asigna un número a cada resultado.
  • Valor esperado $E(X) = \sum_i x_i\,p(x_i)$
  • Varianza $\text{Var}(X) = \sum_i x_i^2\,p(x_i) - [E(X)]^2$
  • Binomial $P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}$, con $E(X)=np$ y $\text{Var}(X)=np(1-p)$

Tutorial resuelto: número de caras al lanzar 3 monedas

Se lanza una moneda equilibrada 3 veces. Sea $X$ = "número de caras obtenidas".

Paso 1 — Espacio muestral

Hay $2^3 = 8$ resultados posibles, todos igualmente probables.

$$\{HHH, HHT, HTH, THH, HTT, THT, TTH, TTT\}$$

Paso 2 — Construir la distribución de probabilidad

Contamos cuántos resultados corresponden a cada valor de $X$.

$x$Resultados$p(x)$
0TTT1/8
1HTT, THT, TTH3/8
2HHT, HTH, THH3/8
3HHH1/8

Paso 3 — Verificar que es una distribución válida

$$\frac{1}{8} + \frac{3}{8} + \frac{3}{8} + \frac{1}{8} = \frac{8}{8} = 1 \ \checkmark$$

Paso 4 — Valor esperado $E(X)$

$$E(X) = 0\cdot\tfrac{1}{8} + 1\cdot\tfrac{3}{8} + 2\cdot\tfrac{3}{8} + 3\cdot\tfrac{1}{8} = \frac{12}{8} = 1.5$$

En promedio, esperamos 1.5 caras cada vez que lanzamos la moneda 3 veces.

Paso 5 — Varianza y desviación estándar

$$E(X^2) = 0^2\cdot\tfrac{1}{8} + 1^2\cdot\tfrac{3}{8} + 2^2\cdot\tfrac{3}{8} + 3^2\cdot\tfrac{1}{8} = \frac{24}{8} = 3$$
$$\text{Var}(X) = E(X^2) - [E(X)]^2 = 3 - 1.5^2 = 3 - 2.25 = 0.75 \qquad \sigma = \sqrt{0.75} \approx 0.866$$

Paso 6 — Reconocer el patrón binomial

Lanzar una moneda 3 veces y contar caras es justamente un experimento binomial con $n = 3$ y $p = 0.5$. Verificamos con las fórmulas directas:

$$E(X) = np = 3(0.5) = 1.5 \ \checkmark \qquad \text{Var}(X) = np(1-p) = 3(0.5)(0.5) = 0.75 \ \checkmark$$

Ambas fórmulas coinciden con lo calculado paso a paso: cuando el experimento cumple las condiciones de una binomial, no hace falta construir toda la tabla.

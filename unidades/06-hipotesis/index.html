Unidad 6

Introducción a pruebas de hipótesis

Hipótesis nula y alternativa, errores tipo I y II, y pruebas para la media y la proporción.

Teoría y tutorial Ejercicios

Una prueba de hipótesis es un procedimiento para decidir, a partir de los datos de una muestra, si una afirmación sobre un parámetro poblacional es creíble o no.

Hipótesis nula y alternativa

La hipótesis nula ($H_0$) es la afirmación que se presume cierta por defecto; la hipótesis alternativa ($H_1$) es lo que se quiere comprobar con los datos. (Walpole et al., 2012, cap. 10)

$$H_0: \mu = 500 \qquad H_1: \mu \ne 500 \ \ (\text{o } \mu < 500 \text{, o } \mu > 500)$$

Es como un juicio: se presume $H_0$ cierta hasta que la evidencia sea suficiente para rechazarla; la prueba nunca "demuestra" que $H_0$ es verdadera, solo dice si hay o no evidencia para rechazarla.

Errores tipo I y tipo II

El error tipo I es rechazar $H_0$ siendo verdadera; el error tipo II es no rechazarla siendo falsa. (Montgomery & Runger, 2014, cap. 9)

$H_0$ es verdadera$H_0$ es falsa
No rechazar $H_0$Decisión correctaError tipo II
Rechazar $H_0$Error tipo I ($\alpha$)Decisión correcta

Siguiendo el juicio: el error tipo I es condenar a un inocente y el error tipo II es absolver a un culpable. Se controla $\alpha$ de antemano porque rechazar una afirmación cierta suele considerarse el error más costoso; $\beta$ no se fija directamente, pero aumentar $n$ lo reduce.

Prueba de hipótesis para la media

Compara la media muestral con el valor propuesto $\mu_0$, en unidades de error estándar (requiere $\sigma$ conocida y $n$ grande, por el TLC de la Unidad 4).

$$Z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}}$$

Ejemplo rápido: con $\bar{x}=52$, $\mu_0=50$, $\sigma=8$ y $n=16$, $Z = \dfrac{52-50}{8/\sqrt{16}} = \dfrac{2}{2} = 1.0$.

Se rechaza $H_0$ si $Z$ cae en la región de rechazo, definida por un valor crítico que depende de $\alpha$ y de si la prueba es de una cola o de dos colas. (Walpole et al., 2012, cap. 10; Montgomery & Runger, 2014, cap. 9)

El valor-p es la probabilidad de obtener un estadístico al menos tan extremo como el observado, si $H_0$ fuera cierta; se rechaza $H_0$ si el valor-p es menor que $\alpha$. Ambos métodos siempre llevan a la misma decisión. (Montgomery & Runger, 2014, cap. 9)

Prueba de hipótesis para una proporción

Compara la proporción muestral $\hat{p}$ con el valor propuesto $p_0$, en unidades de error estándar.

$$Z = \frac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}}$$

Ejemplo rápido: con $\hat{p}=0.6$, $p_0=0.5$ y $n=100$, $Z = \dfrac{0.6-0.5}{\sqrt{0.5(0.5)/100}} = \dfrac{0.1}{0.05} = 2.0$.

Se usa la misma tabla de valores críticos y la misma regla de decisión. (Walpole et al., 2012, cap. 10)

Relación entre el intervalo de confianza y la prueba de hipótesis

Una prueba de dos colas con significancia $\alpha$ equivale a construir un intervalo de confianza del $(1-\alpha)\times 100\%$ para $\mu$ y ver si $\mu_0$ cae dentro: si queda fuera, se rechaza $H_0$; si queda dentro, no se rechaza. (Walpole et al., 2012, cap. 10)

Con los datos del tutorial de la batería ($\bar{x}=485$, $\sigma_{\bar{x}}=60/\sqrt{36}=10$), el intervalo del 95% es $485 \pm 1.96(10) = (465.4,\ 504.6)$. Como $\mu_0 = 500$ cae dentro, no se rechaza $H_0$ — la misma conclusión que con el estadístico $Z$.

Resumen — para recordar

  • $H_0$ hipótesis nula (se presume cierta) — $H_1$ hipótesis alternativa (lo que se quiere comprobar)
  • Error tipo I ($\alpha$) — rechazar $H_0$ siendo verdadera. Error tipo II — no rechazar $H_0$ siendo falsa.
  • Estadístico (media) $Z = \dfrac{\bar{x}-\mu_0}{\sigma/\sqrt{n}}$
  • Estadístico (proporción) $Z = \dfrac{\hat{p}-p_0}{\sqrt{p_0(1-p_0)/n}}$
  • Decisión — se rechaza $H_0$ si $|Z|$ supera el valor crítico, o si el valor-p es menor que $\alpha$.

Tutorial resuelto: vida útil de una batería

Un fabricante afirma que sus baterías duran, en promedio, al menos 500 horas ($\mu_0 = 500$). Un grupo de consumidores sospecha que la duración real es menor y prueba una muestra aleatoria de $n = 36$ baterías, obteniendo $\bar{x} = 485$ horas. Se sabe que $\sigma = 60$ horas. ¿Hay evidencia, con $\alpha = 0.05$, de que la duración media real es menor a 500 horas?

Paso 1 — Plantear las hipótesis

Como se quiere comprobar si la duración es menor, es una prueba de una cola (izquierda).

$$H_0: \mu = 500 \qquad H_1: \mu < 500$$

Paso 2 — Nivel de significancia y valor crítico

Para $\alpha = 0.05$ y una cola, el valor crítico es $z_c = 1.645$; como la alternativa es "menor que", la región de rechazo es $Z < -1.645$.

Paso 3 — Calcular el estadístico de prueba

$$Z = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}} = \frac{485 - 500}{60/\sqrt{36}} = \frac{-15}{10} = -1.5$$

Paso 4 — Comparar con la región de rechazo

Como $-1.5$ no es menor que $-1.645$ (está más cerca de 0), el estadístico no cae en la región de rechazo.

Paso 5 — Confirmar con el valor-p

$$\text{valor-p} = P(Z < -1.5) = 1 - \Phi(1.5) = 1 - 0.9332 = 0.0668$$

Como $0.0668 > 0.05$, llegamos a la misma conclusión: no hay evidencia suficiente para rechazar $H_0$.

Paso 6 — Interpretar el resultado

Con un 5% de significancia, no rechazamos $H_0$: los datos no dan evidencia suficiente para concluir que la duración media real es menor a 500 horas. Esto no prueba que la afirmación del fabricante sea cierta, solo que esta muestra no alcanza para refutarla.

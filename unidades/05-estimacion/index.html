Unidad 5

Estimación

Estimación puntual, intervalos de confianza y tamaño de muestra.

Teoría y tutorial Ejercicios

Introducción

Casi nunca conocemos el verdadero valor de un parámetro poblacional (como $\mu$ o $p$); solo tenemos datos de una muestra. Estimar es usar esos datos para aproximar el parámetro, y hay dos formas de hacerlo: con un solo número (estimación puntual) o con un rango de valores plausibles (estimación por intervalos).

Estimación puntual

La estimación puntual usa un solo número de la muestra para aproximar el parámetro poblacional.

$$\bar{x} \ \text{estima a}\ \mu \qquad\qquad \hat{p} \ \text{estima a}\ p$$

Ejemplo: en una muestra de 49 estudiantes, $\bar{x} = 15$ horas es la estimación puntual del tiempo de estudio semanal promedio $\mu$.

Un estimador puntual casi nunca acierta exactamente, y no dice qué tan cerca está del valor real; para eso se usa la estimación por intervalos.

Estimación por intervalos

La estimación por intervalos da un rango de valores plausibles para el parámetro, junto con un nivel de confianza que indica qué tan seguido ese procedimiento produce un intervalo que sí lo contiene (Walpole et al., 2012, cap. 9).

Ejemplo: en vez de decir "$\mu \approx 15$", decimos que $\mu$ está en $(13.824,\ 16.176)$ con 95% de confianza (ver el tutorial de esta unidad).

El 95% describe qué tan seguido el método acierta al repetirse, no la probabilidad de que $\mu$ esté en este intervalo específico ya calculado.

Intervalo de confianza para la media

Es el rango que resulta de sumar y restar a $\bar{x}$ un margen de error basado en el error estándar.

$$\bar{x} \pm z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}}$$
Nivel de confianza90%95%99%
$z_{\alpha/2}$1.6451.962.576
$$\bar{x}=15,\ \sigma_{\bar{X}}=0.6,\ 95\%:\quad 15 \pm 1.96(0.6) = 15 \pm 1.176 \ \Rightarrow\ (13.824,\ 16.176)$$

A mayor nivel de confianza, mayor $z_{\alpha/2}$ y más ancho el intervalo.

Intervalo de confianza para una proporción

Sigue la misma lógica que para la media, pero usa el error estándar de $\hat{p}$.

$$\hat{p} \pm z_{\alpha/2} \cdot \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$$
$$\hat{p}=0.4,\ n=100,\ 95\%:\quad 0.4 \pm 1.96\sqrt{\tfrac{0.4(0.6)}{100}} = 0.4 \pm 0.096 \ \Rightarrow\ (0.304,\ 0.496)$$

Tamaño de muestra

Si en cambio queremos fijar de antemano el margen de error máximo $E$, despejamos $n$ de la fórmula del margen de error $E$ (Walpole et al., 2012, cap. 9).

$$n = \left(\frac{z_{\alpha/2}\,\sigma}{E}\right)^2$$
$$\sigma=4.2,\ z_{\alpha/2}=1.96,\ E=1:\quad n = \left(\frac{1.96 \times 4.2}{1}\right)^2 = 67.77 \ \Rightarrow\ n = 68$$

El resultado siempre se redondea hacia arriba, para que el margen de error no supere lo pedido.

Resumen — para recordar

  • IC para la media $\bar{x} \pm z_{\alpha/2}\cdot\dfrac{\sigma}{\sqrt{n}}$
  • IC para una proporción $\hat{p} \pm z_{\alpha/2}\cdot\sqrt{\dfrac{\hat{p}(1-\hat{p})}{n}}$
  • Valores comunes de $z_{\alpha/2}$ — 90%: 1.645, 95%: 1.96, 99%: 2.576
  • Tamaño de muestra $n = \left(\dfrac{z_{\alpha/2}\,\sigma}{E}\right)^2$

Tutorial resuelto: tiempo de estudio semanal

Se toma una muestra aleatoria de $n = 49$ estudiantes y se registra su tiempo de estudio semanal, obteniendo una media muestral $\bar{x} = 15$ horas. Se sabe, por estudios previos, que la desviación estándar poblacional es $\sigma = 4.2$ horas. Construye un intervalo de confianza del 95% para la media poblacional.

Paso 1 — Estimación puntual

$$\bar{x} = 15 \text{ horas}$$

Paso 2 — Elegir el nivel de confianza

Para 95% de confianza, usamos $z_{\alpha/2} = 1.96$ (tabla anterior).

Paso 3 — Calcular el error estándar

$$\sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}} = \frac{4.2}{\sqrt{49}} = \frac{4.2}{7} = 0.6$$

Paso 4 — Calcular el margen de error

$$E = z_{\alpha/2} \cdot \sigma_{\bar{X}} = 1.96 \times 0.6 = 1.176$$

Paso 5 — Construir el intervalo

$$15 \pm 1.176 \quad \Rightarrow \quad (13.824,\ 16.176)$$

Paso 6 — Interpretar el resultado

Con un 95% de confianza, la media poblacional del tiempo de estudio semanal de los estudiantes está entre 13.82 y 16.18 horas. Esto significa que, si repitiéramos este procedimiento de muestreo muchas veces, aproximadamente el 95% de los intervalos construidos así contendrían el verdadero valor de $\mu$.

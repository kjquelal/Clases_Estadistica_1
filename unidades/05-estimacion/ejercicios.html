Teoría y tutorial Ejercicios

Usa la tabla de valores críticos de la página de teoría: 90% → $z_{\alpha/2}=1.645$, 95% → $z_{\alpha/2}=1.96$, 99% → $z_{\alpha/2}=2.576$.

Ejercicio 1 Básico

Una muestra de 64 focos LED tiene una vida media $\bar{x} = 800$ horas. Se sabe que $\sigma = 48$ horas. Construye un intervalo de confianza del 90% para la vida media poblacional.

Ver solución
$$\sigma_{\bar{X}} = \frac{48}{\sqrt{64}} = \frac{48}{8} = 6$$
$$E = 1.645 \times 6 = 9.87$$
$$800 \pm 9.87 \quad \Rightarrow \quad (790.13,\ 809.87) \text{ horas}$$
Ejercicio 2 Básico

En una encuesta a 400 personas, 260 dijeron apoyar una nueva medida municipal. Calcula la proporción muestral $\hat{p}$ y construye un intervalo de confianza del 95% para la proporción real de apoyo.

Ver solución
$$\hat{p} = \frac{260}{400} = 0.65$$
$$\sigma_{\hat{p}} = \sqrt{\frac{0.65(0.35)}{400}} = \sqrt{0.00056875} \approx 0.0238$$
$$E = 1.96 \times 0.0238 \approx 0.0467$$
$$0.65 \pm 0.0467 \quad \Rightarrow \quad (0.603,\ 0.697)$$
Ejercicio 3 Intermedio

Un fabricante mide el contenido de 100 latas de refresco y obtiene $\bar{x} = 354$ ml, con $\sigma = 6$ ml conocida. Construye un intervalo de confianza del 99% para el contenido medio poblacional. El fabricante afirma que el contenido promedio real es de 355 ml: ¿es creíble esa afirmación según tu intervalo?

Ver solución
$$\sigma_{\bar{X}} = \frac{6}{\sqrt{100}} = \frac{6}{10} = 0.6$$
$$E = 2.576 \times 0.6 = 1.546$$
$$354 \pm 1.546 \quad \Rightarrow \quad (352.454,\ 355.546) \text{ ml}$$

Como 355 ml cae dentro del intervalo, la afirmación del fabricante es creíble con un 99% de confianza: no hay evidencia suficiente para descartarla.

Ejercicio 4 Avanzado

Se quiere estimar el tiempo de reacción promedio de conductores. Estudios previos indican $\sigma = 1.2$ segundos. ¿Qué tamaño de muestra se necesita para que el margen de error sea de a lo sumo $E = 0.3$ segundos, con 95% de confianza?

Ver solución
$$n = \left(\frac{z_{\alpha/2}\,\sigma}{E}\right)^2 = \left(\frac{1.96 \times 1.2}{0.3}\right)^2 = \left(\frac{2.352}{0.3}\right)^2 = (7.84)^2 = 61.47$$

Redondeando hacia arriba, se necesita una muestra de al menos $n = 62$ conductores.
